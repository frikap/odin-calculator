# Calculator

A clean, responsive, and user-friendly web calculator built with HTML, CSS, and JavaScript, built as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum.

## Features

- **Core Math Operations**: Addition (`+`), Subtraction (`−`), Multiplication (`×`), and Division (`÷`).
- **Chained Calculations**: Chain consecutive operations smoothly without having to press equals every time (e.g., `12 + 8 ÷ 4`).
- **Division by Zero Protection**: Graceful handling with a humorous prompt (`"Good try, Einstein!"`) when dividing by zero.
- **Smart Decimal Input**: Prevents multiple decimal points in a single operand.
- **Quick Correction Controls**:
  - **`AC` (All Clear)**: Resets all stored values and display state.
  - **`DEL` (Delete / Backspace)**: Erases the last typed digit.
- **Full Physical Keyboard Support**: Complete control directly from your keyboard.

## Built With

- **HTML5**: Semantic markup for the calculator structure and accessible layout.
- **CSS3**: CSS Grid for keypad layout, Flexbox for screen centering and display alignment, responsive dimensions, and interactive button active/hover states.
- **JavaScript**: Modular arithmetic functions, state management, event listeners, and keyboard event bindings.
